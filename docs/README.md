# FAME-Net project page

Static, responsive website without a build step. Preview from the repository root:

```sh
python -m http.server 8000 --directory docs
```

To publish, enable GitHub Pages at https://github.com/alexhe101/FAME-Net/settings/pages: Deploy from a branch, main, /docs. The expected URL is https://alexhe101.github.io/FAME-Net/.

Results are taken from the published AAAI paper. The architecture SVG is a conceptual redraw, not model output. The qualitative panel links to the HFIPS research announcement, with a PDF fallback. External image availability is not guaranteed.
